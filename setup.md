# Setup Instructions

## Prerequisites

* Node.js 18+
* Python 3.10+
* npm

---

## Clone Repository

```bash
git clone <repository-url>

cd aion
```

## Backend Setup

```bash
cd backend

pip install -r requirements.txt

python app.py
```

Backend runs on:

```text
http://localhost:5000
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```text
http://localhost:3000
```

---

## Running AION

1. Start backend.
2. Start frontend.
3. Open the frontend in the browser.
4. Use disturbance controls to simulate industrial events.
5. Observe risk calculations, AI severity predictions, recommendations, and digital twin updates.
